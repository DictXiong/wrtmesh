# wrtmesh v6.4.2

Frontend candidate; no release is published by this change.

Overview now uses one compact client table with visible MAC addresses, host/IP,
SSID/node, signal and AP RX/TX. Node freshness and failure notices remain visible.
Per-client disclosure controls have been removed.

The Mesh page adds always-visible band/channel, interface/BSSID and observed
MLO link rows. Client report and per-link measurements remain distinct, and
missing per-link values are not filled from the parent. Both views share the
same table and host/IP formatting, with client cards at narrow content widths.

Collectors, RPC, peer communication, UCI, service startup, roaming decisions
and configuration policy are unchanged. Acceptance is limited to frontend
syntax, translations and Chromium with actual LuCI modules and GlassTheme CSS;
no device installation, firmware build or wireless acceptance is part of this
UI candidate.
