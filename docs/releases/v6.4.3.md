# wrtmesh v6.4.3

Each Mesh client now occupies one outer table row. Its reported MLO links stay
in a compact diagnostic grid within that row, keeping columns aligned without
isolated partial-row hover shading. Missing or invalid RSSI, including zero,
shows an em dash; valid negative RSSI and observed link fields are preserved.

This is a frontend-only update. Collectors, RPC, protocol, configuration,
services and roaming decisions are unchanged. The stylesheet URL carries the
UI version so a package update can retrieve its matching CSS.
