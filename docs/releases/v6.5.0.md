# wrtmesh v6.5.0

Local AP/SSID readiness now distinguishes the wrtmesh worker, configured options,
available hostapd APIs and runtime evidence. Neighbor reporting is required for
assistance; missing or partial firmware support is shown as unsupported or unknown.
Beacon measurement, BSS Transition and FT remain optional and read-only here.

With reliable support and normal wireless UCI permission, users can preview and
stage only the selected AP's neighbor-report flag. Save does not apply changes or
reload wireless. Application remains an explicit action in LuCI's standard changes
and rollback flow; existing wireless edits are preserved and block a conflicting save.

A new read-only readiness RPC exposes nonsecret flag metadata and existing local
runtime/report evidence without adding background sampling or changing collectors,
roaming, peer protocols, service behavior, native code or firmware. No wireless write
permission is added to the Mesh ACL, and no wpad replacement or FT setup is performed.
Normal package upgrade hooks still stop/start wrtmesh and reload rpcd.
