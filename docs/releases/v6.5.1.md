# wrtmesh v6.5.1

Neighbor-report staging rechecks pending and local unsaved wireless changes after
awaiting readiness and immediately before the single standard UCI set call. Changes
observed during readiness inspection block staging and remain untouched. Standard
UCI still provides no atomic compare-and-set across tabs.

Package ownership metadata includes the new read-only readiness module. This
corrects the compatibility file list; APK payload metadata already owned the module.
Collectors, RPC implementations and ACL, roaming, configuration defaults and all
package lifecycle hooks are unchanged from v6.5.0. Save still only stages one flag;
application stays in the standard LuCI changes and rollback flow.
