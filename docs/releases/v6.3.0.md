# wrtmesh v6.3.0

Local roaming profiles can now be configured in **Network → Mesh**. Create,
edit, enable, disable or remove a profile, select an actual local SSID, and set
its check and expiry intervals. Runtime interface and MLO metadata come from
netifd and hostapd. The peer editor labels BSSID approvals with the local SSID
and stable profile ID, including disabled profiles. No SSID presets are shipped.

The configuration files, init service, library directory, RPC object, LuCI
modules and discovery advertisement now use the `wrtmesh` name. Earlier local
configuration files are backed up byte-for-byte and migrated automatically.
Existing populated new configuration takes precedence. Keep settings when
performing a firmware upgrade. External provisioning must switch to the new
paths and service name as well.

Read-only HTTP aliases and bounded discovery/fetch fallbacks preserve v1 peer
communication with earlier nodes. Configuration changes remain restricted to
authenticated local LuCI RPC; the plaintext peer API cannot change settings.

The package owns its native Overview include and Mesh page. Installation,
upgrade and removal do not patch or replace LuCI files. Reload open browser
tabs after a package change. Roaming still requires the supported hostapd API;
installing the package does not change wireless security or create SSIDs.
