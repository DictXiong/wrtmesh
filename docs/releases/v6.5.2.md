# wrtmesh v6.5.2

Mesh can now use HTTPS for peer identity, status and neighbor reports. Open
**Network → Mesh → Mesh transport** to enable **Force HTTPS for Mesh peers**.
The setting is off by default. In that mode, requests start over HTTP and can
follow one HTTPS redirect to the same peer and resource on port 443. When
enabled, all three requests use HTTPS directly on port 443.

Both modes accept the peer's existing certificate, including self-signed
certificates. HTTPS encrypts the requests without verifying the certificate.
The existing management LAN, peer identity and report validation still apply.
