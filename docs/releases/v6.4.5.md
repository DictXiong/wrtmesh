# wrtmesh v6.4.5

Correct the shared stylesheet URL in Overview and Mesh. The query suffix is
appended after LuCI resolves the CSS path, so LuCI no longer discards a combined
filename/query argument and requests a resource directory as a stylesheet.
This restores topology colors and lines, SSID/interface and AP RX/TX line breaks,
and the existing grouped SSID cards without changing their layouts or data.
On narrow screens, the topology keeps its native text size inside the existing
horizontal scroll container instead of shrinking labels below readable size.

Browser checks use the actual LuCI resource URL methods and verify that the
component's stylesheet link loads CSS and applies SVG styles. The collectors,
RPC, polling, roaming logic and service definitions are unchanged. Normal APK
upgrade hooks still stop/start wrtmesh and reload rpcd.
