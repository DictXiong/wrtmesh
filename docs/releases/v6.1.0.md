# wrtmesh 6.1.0

First standalone release of the XR1710G roaming and Mesh package. LuCI's
Network → Mesh page provides peer discovery, station inventory and bridge-port
topology. Firmware builds can apply the included LuCI Overview patch.

The APK replaces `xr-roaming` and retains its UCI files, service name and
version 1 neighbor-report endpoint. See the README for the package upgrade
command and compatible C7 firmware.
