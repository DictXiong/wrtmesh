# wrtmesh v6.4.4

Mesh uses the shared five-column client table: SSID/node and reported interface,
client MAC, host/IP, signal, and negotiated AP RX/TX. Each client occupies one
row, including MLO clients. Link subrows, grids and repeated AP properties are
removed; unknown RSSI remains an em dash.

The existing SSID roaming section groups peers by SSID and summarizes band and
channel from current neighbor reports once per node/SSID. Reports are deduplicated
by BSSID; same-channel radios retain a count. Expired or unavailable data is
marked. Report count does not imply MLO membership, and no client measurements
are used to guess AP properties.

This frontend update supersedes the v6.4.3 UI candidate. Collectors, RPC, protocol,
configuration, services and roaming decisions remain unchanged, with no extra
queries or sampling. Normal package upgrade hooks still stop/start wrtmesh and
reload rpcd; install in an appropriate service window.
