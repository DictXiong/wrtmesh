# wrtmesh v6.4.1

Declarative provisioners can select roaming SSIDs in `/etc/config/wrtmesh`
using automatic peer policy. They provide only peer IPv4, bridge MAC and exact
SSID names; BSSIDs and link reports remain learned runtime state. Local worker
names do not need to match across nodes.

LuCI continues to own its separate per-peer override file. Edits and deletion
markers override provisioned policy. Both configuration sources use the same
identity checks, cache freshness rules and hostapd application proof, including
when the LuCI override file is empty. Existing pinned relationships remain
supported.
